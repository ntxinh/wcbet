# CupClash

World Cup score-prediction game: pick a name, predict exact scores before kickoff, earn 3/1/0 points, climb the leaderboard.

Next.js 16 (App Router) + React 19 + Tailwind v4 + Drizzle/Postgres + TanStack Query + Zustand.

## Getting started

See [docs/SETUP.md](docs/SETUP.md) for toolchain, env, and database setup. Then:

```bash
pnpm dev
```

API reference lives at `/api/docs` when the dev server is running (spec: `lib/openapi.ts`, also in [docs/API.md](docs/API.md)).
